# Optional parameter metadata — archived proposal summary

**Historical summary, superseded by [SWSS v2.0](../../standards/SWSS/v2.0.md).** This file was explicitly condensed and made application-neutral under issue #20 on 2026-10-19; it is not an active design gate or another specification.

Issue #16 established the single `swss.toml` direction: portable scientific metadata, optional parameter rows, script authority, exact argv preservation, data-only discovery, bounded parsing, metadata consistency, optional source hashes and manual fallback. The subsequent v1.1 specification incorporated that design. v2.0 retains these protections while replacing application-oriented profiles and configuration namespaces with independent capabilities and bounded generic extensions under schema 2.

Original proposal text remains at Git commit `63065f203b526704a37c8f88d6d5e6ea3bc9b5dc`, at this path. No history was rewritten and no externally recorded scientific evidence was modified. Earlier implementation observations are historical, not evidence of current consumer support. This summary grants no authority for external implementation, conversion, release or certification.

See the current specification for complete requirements, examples and conformance cases. Authorship and [licensing](../../LICENSE.md) are unchanged.
