# Historical consolidation and v2.0 reconciliation

**Modified historical summary, 2026-10-19.** The earlier v1.0 review consolidated detailed and modular drafts. Its original report is preserved at Git commit `63065f203b526704a37c8f88d6d5e6ea3bc9b5dc`, at this path. This owner-authorized neutral summary does not restate the original application contracts as universal requirements.

The [v2.0 specification](../standards/SWSS/v2.0.md) replaces product-oriented profiles with a baseline and independent capabilities. This is a breaking revision, with portable schema 2 and explicit adoption review; earlier labels do not prove new conformance.

| Earlier guarantee or boundary | v2.0 disposition |
| --- | --- |
| Scientific authority, versioning, exact source and resolved parameters | §2 baseline, retained; labels, snapshots and structural fingerprints remain distinct. |
| Unique logs/output roots, truthful lifecycle, diagnostics, backups | §2 baseline, retained with success/failure/cancellation and concurrency cases. |
| Agreed capture root, automatic copied logs, process streams, budgets and source exclusions | §3.1 optional capability, transport and policy documented by adapters; no named environment variable or UI default prescribed. |
| Finite/indeterminate progress, metrics, real solver time, nonfinite handling | §3.2 optional capability, without prescribing an API or text parser. |
| Exclusive artifact creation, collision refusal, scientific quantities, numerical readback and partial evidence | §3.3 optional export capability; no external binary format relabeled as SWSS. Format/version and reader coverage must be recorded. |
| Restart lineage and full solver state | §2 baseline when checkpoints are provided; visualization alone is insufficient. No checkpoint protocol added. |
| Single configuration, optional declarations, exact argv, bindings, provenance and bounds | §4, preserved; schema 2 replaces consumer-owned root namespaces with optional generic extensions. |
| Runtime tests and external implementation | §5 requires evidence; documentation checks do not complete runtime gates. |
| Historical scientific evidence, ownership and licensing | Preserved; current tracked historical prose is explicitly summarized, original Git history untouched. |

The current [review checklist](REVIEW.md) remains unchecked pending implementation evidence. No scientific pilot, live recorder or exporter was exercised by this reconciliation. [Authorship and licensing](../LICENSE.md) are unchanged.
